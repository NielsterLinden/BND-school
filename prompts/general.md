To use the fitting use TReXFitter, so make the histograms for the fits such that one can use the same code base for all. For the analysis code create python files using uproot. Then create the normal root histograms that are going to be fed into the TREXfitter. Clone the TRexfitter and make them as a git submodule. 

The idea is to perform 3 cross section measurements: Z to ee, mumu and tautau, and a combination. In order to perform the combination the 3 subfolders got a handoff.md file to help the combination.

Familiarise yourself with the github repo.

In the end I want you to produce a presenatation covering the whole analysis strategy and the results. The presentation is the final deliverable. Use latex to make the presentation. The presentation style is described in prompts/presentation_style.md
